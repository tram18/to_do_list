# To-Do List Application (Java + REST API)

This project is a **To-Do List** application built using **Spring Boot**.  
It allows users to create, update, delete, and manage to-do lists and their items efficiently.

---

## 🧩 Features
- Create and update to-do lists  
- Delete items from a list  
- Update list names dynamically  
- RESTful API for frontend integration  
- Built with Spring Boot and JPA (Hibernate) for persistence  

---

## 🛠️ Technologies Used
- Java 17+  
- Spring Boot  
- Spring Data JPA / Hibernate  
- Maven  
- H2 / MySQL (depending on your configuration)

---
